
# AI Developers Teams

Мультиагентная система искусственного интеллекта, в которой несколько ИИ-агентов работают как единая команда разработчиков.

## Возможности

- **Менеджер** — распределяет задачи и координирует команду.
- **Архитектор** — проектирует структуру решения.
- **Разработчик** — помогает создавать и улучшать код.
- **Ревьюер** — проверяет качество кода.
- **Тестировщик** — отвечает за тестирование.
- **Аудитор** — проверяет безопасность и результат.

## Архитектура

```text
backend/
├── agents/          # ИИ-агенты и их запуск
├── ai_engine/       # Подключение ИИ-провайдера
├── coordinator/     # Планирование задач
├── memory/          # Память агентов
├── meetings/        # Совещания и голосования
├── backend/
│   ├── main.py      # FastAPI API
│   └── tests/       # Автоматические тесты
└── config.py        # Настройки
```

## Установка

Требуется Python 3.11 или новее.

```bash
git clone https://github.com/cyberbelyashik-lab/AI-Developers-Teams.git
cd AI-Developers-Teams
pip install -r requirements.txt
```

## Настройка ИИ

Создай файл `.env` в корне проекта:

```env
AI_API_KEY=your_api_key
AI_MODEL=your_model
AI_BASE_URL=https://api.openai.com/v1
```

Не публикуй настоящий API-ключ в GitHub.

## Запуск

```bash
uvicorn backend.backend.main:app --reload
```

Документация API после запуска:

- `/docs` — интерактивная документация.
- `/health` — проверка работоспособности.
- `/agents` — список агентов.

## Тестирование

```bash
python -m pytest -v
```

GitHub Actions автоматически запускает тесты при изменениях в репозитории.

## Статус проекта

Проект находится в активной разработке. Новые функции, тесты и улучшения добавляются постепенно.

## Безопасность

- Не добавляй `.env` в репозиторий.
- Не публикуй API-ключи и пароли.
- Проверяй изменения перед слиянием.
